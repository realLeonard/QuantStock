# v3 板块预测系统 — 完整逻辑梳理

## 总流程（scoring.py，8 个步骤）

```
数据查询 → 全局过滤 → 市场环境分级 → 复盘回填 → 全市场基准 → 逐板块评分 → 排序+信号分档+去重 → 写入DB
```

## 总分公式

```
raw = 资金暗流×0.30 + 量价蓄势×0.25 + 模式匹配×0.20 + 催化剂×0.15
combined_coeff = max(0.5, 阶段系数 × 大盘系数)
final = max(0, raw × combined_coeff + 风险修正)
```

## [步骤 1] 数据查询

| 数据 | 查询方式 | 后续用途 |
|---|---|---|
| `sector_daily` 近 60 天 | `select *`，按板块名分组，每组按 trade_date ASC 排序 | 几乎所有评分模块 |
| `limitUpReasons` 当日 | `pick_date = today` | 传给催化剂/风险/生命周期 |
| `limitUpReasons` 近 3 天 | `pick_date` 范围查询，取最后 3 条 | 同上 |
| `dailyReview` 当日 | `report_date = today` | 市场环境分级 |
| `sector_rotation_map` 全量 | `select *` | 催化剂 - 轮动传导 |
| `sector_master` | `is_active = true`，取 `name` + `leading_stock` | 领涨股映射（写入结果用） |

如果今日无 sector_daily 数据，自动退回到最近交易日。

## [步骤 2] 全局过滤

从全部板块中筛出参与评分的板块，3 个条件全部满足才参与：

| 条件 | 逻辑 | 用到的字段 |
|---|---|---|
| 有今日数据 | `rows[-1].trade_date == today` | `trade_date` |
| 至少 20 天历史 | `len(rows) >= 20` | 行数 |
| 成交额 ≥ P20 | 今日成交额 ≥ 全市场当日成交额的第 20 百分位 | `turnover` |

典型结果：~490 个板块过滤后剩 ~390 个参与评分。

---

## [步骤 3] 市场环境分级（market_env.py）

**数据来源**：`dailyReview.market_sentiment`（JSONB），取 3 个字段：

| 字段 | 含义 |
|---|---|
| `limit_up` | 全市场涨停家数 |
| `limit_down` | 全市场跌停家数 |
| `broken_rate` | 炸板率（%） |

**判断逻辑**（按优先级）：

| 等级 | 条件 | 大盘系数 | 推荐上限 |
|---|---|---|---|
| extreme | 跌停 > 30 | ×0.5 | 1 个 |
| strong | 涨停 > 50 且 炸板率 < 20% | ×1.0 | 10 个 |
| weak | 涨停 < 20 且 炸板率 > 40% | ×0.75 | 3 个 |
| neutral | 其余 / 无数据 | ×0.9 | 5 个 |

## [步骤 4] 复盘回填（backfill.py）

对昨日评分结果回填实际涨幅，计算命中率。不影响当日评分，纯记录。

## [步骤 6] 逐板块评分 — 4 个维度 + 风险 + 生命周期

---

### 6.1 资金暗流（fund_stealth_scorer.py，权重 30%，满分 100）

**核心思路**：资金在偷偷进场，但价格还没涨起来。

**数据**：sector_daily 的 `main_net_inflow`、`super_large_net`、`large_net`、`small_net`、`turnover`、`change_pct` + 全市场当日资金流入列表

#### 隐蔽度修正（全局系数）

```
stealth_gap = 资金流入百分位 - 涨幅百分位
```
- 资金流入百分位：当前板块今日 main_net_inflow 在全市场中的排名位置
- 涨幅百分位：用 `change_pct × 15 + 50` 粗略映射（非精确百分位）

| stealth_gap | 系数 | 含义 |
|---|---|---|
| > 30 | ×1.2 | 资金远高于涨幅，在暗中吸筹 |
| 10~30 | ×1.0 | 正常 |
| 0~10 | ×0.8 | 稍有暴露 |
| < 0 | ×0.5 | 资金和涨幅同步，已被市场发现 |

#### 子因子 A：渐进式流入（40 分）

用最近 10 天有资金流数据的记录：
- 从最后一天往前数连续正流入天数
- ≥3 天：基础 20 分 + 每多 1 天 +4，封顶 40
- <3 天：天数 ×5（即 0/5/10）
- **惩罚**：今日流入 > 全市场 P80 → 分数 ×0.5（流入太大已被发现）
- **加分**：后 3 天均值 > 前 3 天均值 ×1.2 → +10 分（递增趋势）

#### 子因子 B：大单暗涌（30 分）

用最近 5 天有资金流数据的记录，逐天检查：
- 条件：`(super_large_net + large_net) / turnover > 0.5%` **且** `change_pct 在 -1%~2%`
- 满足天数 ×6，封顶 30
- 额外：大单占比 5 日均值 > 2% → +5

#### 子因子 C：散户反向（30 分）

用最近 5 天，逐天检查：
- 条件：`small_net < 0` **且** `main_net_inflow > 0`（主力进散户跑）
- 满足天数 ×6，封顶 30

**最终**：`(A + B + C) × 隐蔽度系数`，clamp 到 0~100

### 6.2 量价蓄势（momentum_scorer.py，权重 25%，满分 100）

**核心思路**：底部整理完毕，量价形态即将突破。

**数据**：sector_daily 的 `close`、`high`、`low`、`volume`、`amplitude`（纯 K 线，不用资金流）

#### 子因子 A：底部量能变化（30 分）

```
vol_ratio = 后 10 天均量 / 前 10 天均量
```

| vol_ratio | 基础分 | 含义 |
|---|---|---|
| 1.0~1.3 | 15 | 温和放量 |
| 1.3~1.8 | 30 | 明显放量不过热 |
| > 1.8 | 20 | 过热减分 |
| ≤ 1.0 | 5 | 缩量 |

**惩罚**：价格位置 > 0.6（不在低位）→ 分数 ×0.5

价格位置 = `(close - 20日最低) / (20日最高 - 20日最低)`

#### 子因子 B：振幅收敛 + 价格位置（30 分）

```
收敛比 = 5日振幅均值 / 20日振幅均值
```

| 收敛比 | 价格位置 | 分数 |
|---|---|---|
| < 0.7 | > 0.6（上沿） | 30 分（即将突破） |
| < 0.7 | 0.3~0.6（中部） | 20 分 |
| < 0.7 | < 0.3（下沿） | 15 分 |
| 0.7~1.0 | 任意 | 10 分 |
| > 1.0 | 任意 | 5 分（发散/分歧） |

#### 子因子 C：均线即将金叉（20 分）

```
MA5 = 近5日close均值
MA10 = 近10日close均值
gap_pct = (MA5 - MA10) / MA10 × 100
```

| 条件 | 分数 |
|---|---|
| MA5 < MA10 且 gap > -0.5% | 20（即将金叉，最佳预测点） |
| MA5 > MA10 且 gap < 1% | 10（刚金叉） |
| MA5 > MA10 且 gap ≥ 1% | 5（已多头排列） |
| MA5 < MA10 且 gap ≤ -0.5% | 0（离金叉远） |

#### 子因子 D：突破前夜（20 分）

```
close 与 20日最高价的距离
```

| 条件 | 分数 |
|---|---|
| close ≥ 最高价 × 0.98 | 20 |
| close ≥ 最高价 × 0.95 | 15 |
| close ≥ 最高价 × 0.90 | 8 |
| < 0.90 | 0 |

**最终**：A + B + C + D，clamp 到 0~100

### 6.3 模式匹配（pattern_scorer.py，权重 20%，满分 100）

**核心思路**：在全市场其他板块历史中找到相似的量价/资金模式，看那些模式之后涨了还是跌了。

**数据**：全市场 `grouped` 所有板块的 sector_daily（`main_net_inflow_pct`、`volume`、`change_pct`）

#### 预计算：全市场模式索引

对全市场每个板块的历史数据做滑窗（窗口 3 天，前瞻 3 天）：
- **资金流模式**：每天 main_net_inflow_pct 的正负符号 → 3 位字符串（如 `++-`），共 2³=8 种
- **量价模式**：每天归类为 4 种状态（放量涨 HU / 放量跌 HD / 缩量涨 LU / 缩量跌 LD，量的基准 = 前 10 日均量） → 3 位字符串（如 `HULUHD`），共 4³=64 种
- 每个匹配窗口记录：板块名 + 后 3 天累计涨幅

**严格约束**：只用 today 之前的数据建索引，不用未来数据。

#### 子因子 A：资金流模式匹配（50 分）

取当前板块最近 3 天的资金流符号序列 → 在索引中查找匹配（排除自身板块） → 需 ≥10 个匹配

| 匹配后 3 天平均涨幅 | 分数 |
|---|---|
| > 2% | 50 |
| 1%~2% | 35 |
| 0%~1% | 20 |
| < 0% | 0 |

#### 子因子 B：量价形态匹配（50 分）

同理，取最近 3 天量价状态序列匹配，映射到分数逻辑相同。

#### 预定义强势模式加分（0~5）

用最近 5 天的量价状态做完整匹配：
- `LDLDLUHUHU`（V 型启动）→ +5
- `LULULULUHU`（蓄势突破）→ +5
- `HUHUHUHUHU`（连续放量涨）→ 不加分（已在主升，追高风险）

**最终**：A + B + 强势加分，clamp 到 0~100

---

### 6.4 催化剂（catalyst_scorer.py，权重 15%，满分 100）

**核心思路**：外部催化因素——政策新闻、产业链轮动、涨停板人气。

#### 子因子 A：政策催化（35 分）

**数据**：`newsItems_cls` 近 3 天

1. 查询近 3 天全部新闻（全局缓存，只查一次）
2. 对当前板块做关键词匹配：`normalize(板块名) in (title + summary)`
3. 如果有匹配新闻 → 调 Claude Sonnet API（结果缓存，同板块不重复调）
4. Claude 收到最多 20 条相关新闻，返回 0~100 的利好评分

| Claude 评分 | 子因子分数 |
|---|---|
| > 60 | 35 |
| 50~60 | 15 |
| < 50 / 无新闻 / API 失败 | 0 |

#### 子因子 B：轮动传导（30 分）

**数据**：`sector_rotation_map`（source_sector → target_sector + weight） + 全市场 sector_daily

1. 查找当前板块作为 target 的上游板块
2. 对每个上游板块检查：
   - 近 3 天累计涨幅 > 5% → +20 × weight
   - 近 3 天资金全部正流入且递增 → +10 × weight
3. 合计 clamp 到 0~30

#### 子因子 C：连板天梯人气（35 分）

**数据**：`limitUpReasons` 近 3 天 → 解析 `themes` JSONB

对当前板块提取每天的：涨停家数（count）、最高连板数（max_board）、是否有 2 板+（has_2board）、首板数量

**互斥取最高分**（满足第一个就不看后面的）：

| 条件 | 分数 | 含义 |
|---|---|---|
| 昨日 0 涨停 → 今日 ≥1 | 35 | 首次出现涨停（启动催化，最有预测价值） |
| 涨停数比昨日增加（且昨日 >0） | 25 | 人气在聚集 |
| 今日出现 2 板+（昨日无） | 20 | 市场开始接力 |
| 首板数量比昨日增加 | 15 | 新资金试探 |
| 最高板 ≥4 | 5 | 已有高位板（预测价值低） |
| 都不满足 | 0 | — |

**最终**：A + B + C，clamp 到 0~100

---

### 6.5 风险修正（risk_adjuster.py，-5 ~ 0 分）

逐条检查，每条 -1~-2，累计最多 -5：

| # | 条件 | 扣分 | 数据来源 |
|---|---|---|---|
| 1 | 连续上涨 > 5 天 | -2 | `change_pct` 倒序连续正值天数 |
| 2 | 今日振幅 > 5% 且近 2 日换手率 > 前 3 日均值 ×1.5 | -2 | `amplitude` + `turnover_rate` |
| 3 | 资金连续流出 ≥ 2 天 | -1 | `main_net_inflow` 倒序连续负值天数 |
| 4 | 今日涨幅 > 5% | -2 | `change_pct` |
| 5 | 最高板断板（昨日最高连板股今日不在涨停列表） | -2 | `limitUpReasons` themes 里的 stocks[].name + board |
| 6 | 涨停数连续 2 天增加 + 最高板 ≥5 | -1 | `limitUpReasons` 近 3 天 count + max_board |
| 7 | 板块跌停家数 > 0 | -1 | `sector_daily.limit_down_count`（**历史全为 0，等于没生效**） |

### 6.6 生命周期（lifecycle.py）→ 阶段系数

**数据**：sector_daily 全量字段 + limitUpReasons 近 3 天

按优先级从高到低匹配，命中即返回：

| 阶段 | 系数 | 条件（任一满足即命中） |
|---|---|---|
| **见顶期** | 0.7 | ① 最高板断板（昨日最高连板股今日消失）<br>② 涨停数连续 2 天增 + 最高板 ≥5（高潮末期）<br>③ 连涨 ≥5 天 + 近 3 日振幅 > 20 日均值 ×2<br>④ 今日涨 > 5% 但资金流出 |
| **调整期** | 0.8 | ① 涨停数减少且今日降为 0（无接力）<br>② 连续 ≥2 天资金流出 + 近 5 日累计涨幅 < 0<br>③ close < MA5 且 MA5 < MA10 |
| **主升期** | 0.9 | ① 涨停数 ≥3 且最高板 ≥3（天梯成型）<br>② 5 日涨 > 5% + 量能放大 > 30% + 连续 ≥3 天流入 |
| **发酵期** | 1.0 | ① 涨停数增加 + 出现 2 板<br>② 量能放大 > 50% + 上涨 2~4 天 |
| **启动期** | 1.1 | ① 首板从无到有（昨 0→今 ≥1）<br>② MA5 刚上穿 MA10 + 量能放大 > 20%<br>③ 首次突破 20 日高点（昨 < high20d，今 ≥ 98%） |
| **吸筹期** | 1.2 | 全部满足：无涨停 + 连续 ≥3 天递增流入 + 价格位置 0.3~0.6 + 振幅收敛（< 均值 70%）+ 成交额 > 自身中位数 |
| **观察期** | 1.0 | 默认（以上全不满足） |

生命周期用到的 sector_daily 字段：`change_pct`、`volume`、`amplitude`、`close`、`high`、`low`、`turnover`、`main_net_inflow`、`turnover_rate`

## [步骤 7] 排序 + 信号分档 + 去重

### 信号分档

按 total_score 降序排名后：

| 信号 | 条件 | 时间建议 |
|---|---|---|
| sell | 见顶期 + 风险修正 ≤ -3 | 建议离场 |
| strong_buy | TOP 5% + 分数 ≥ 60 + 吸筹期/启动期 | 中期布局(3-5天) |
| buy | TOP 10% + 分数 ≥ 50 + 非见顶/调整 | 短期机会(1-3天) |
| hold | 主升期/发酵期 + 分数 ≥ 50 | 持有观察 |
| watch | TOP 40% | 关注 |
| avoid | 其余 | 回避 |

### 板块去重

对 strong_buy / buy / hold 板块两两计算近 20 日 change_pct 的相关系数，相关系数 > 0.8 的视为重叠，保留分数高的那个，另一个降为 watch。

---

## [步骤 8] 写入 sector_scores

删除当日已有记录 → 批量插入（每批 50 条，带 3 次重试）。

