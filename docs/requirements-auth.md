# 需求文档：多用户登录与角色权限系统

**项目**：股海远洋（QuantStock）
**版本**：v1.1.0
**日期**：2026-03-14
**状态**：待评审

---

## 一、背景与目标

当前系统仅支持单一硬编码账号（admin/123456），无法满足多人协作场景。本次升级目标：

1. 支持多用户独立账号登录
2. 引入角色权限体系，按角色控制操作权限
3. 提供用户管理界面，admin 可维护账号和角色
4. 提供角色说明页，展示各角色权限范围

---

## 二、角色定义

系统内置三个固定角色，不可自定义：

| 角色 | 英文标识 | 权限范围 |
|------|---------|---------|
| 管理员 | admin | 查看数据 + 增删改主题/股票 + 管理用户账号 |
| 编辑者 | editor | 查看数据 + 增删改主题/股票 |
| 观察者 | viewer | 仅查看数据，不可进行任何写操作 |

- 每个角色可对应任意数量的用户（多对一）
- 角色权限固定，如需调整需修改代码

## 三、功能需求

### 3.1 登录功能

| 编号 | 需求描述 | 优先级 |
|------|---------|--------|
| F-01 | 用户输入用户名和密码登录 | P0 |
| F-02 | 密码以 bcryptjs 哈希存储，服务端比对 | P0 |
| F-03 | 登录成功后 sessionStorage 保存用户信息（用户名、角色），刷新页面可恢复登录态 | P0 |
| F-04 | 登录失败显示「账号或密码错误」提示 | P0 |
| F-05 | 退出登录清除 sessionStorage，返回登录页 | P0 |

### 3.2 权限控制

| 编号 | 需求描述 | 优先级 |
|------|---------|--------|
| F-06 | viewer 登录后，所有新增/编辑/删除按钮不渲染（不可见） | P0 |
| F-07 | editor 登录后，可正常操作主题和股票的增删改 | P0 |
| F-08 | admin 登录后，拥有 editor 全部权限，额外可访问用户管理和角色管理 | P0 |
| F-09 | 侧边栏「用户管理」「角色管理」入口仅 admin 可见 | P0 |

### 3.3 用户管理（admin 专属）

| 编号 | 需求描述 | 优先级 |
|------|---------|--------|
| F-10 | 用户列表展示：用户名、角色、创建时间、操作 | P0 |
| F-11 | 新增用户：填写用户名、初始密码、选择角色 | P0 |
| F-12 | 修改角色：在列表中直接修改某用户的角色 | P0 |
| F-13 | 重置密码：输入新密码，哈希后更新 | P0 |
| F-14 | 删除用户：不可删除当前登录的自己 | P0 |
| F-15 | 用户名唯一校验，创建时重名提示错误 | P1 |

### 3.4 角色管理（admin 专属，只读）

| 编号 | 需求描述 | 优先级 |
|------|---------|--------|
| F-16 | 以卡片形式展示三个内置角色及其权限说明 | P1 |
| F-17 | 页面顶部注明「角色权限为系统内置，如需调整请联系开发者」 | P1 |

## 四、数据库设计

### 新增表：adminUsers

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 唯一标识（uid 生成）|
| username | TEXT UNIQUE | 用户名，不可重复 |
| password_hash | TEXT | bcrypt 哈希值 |
| role | TEXT | 枚举：viewer / editor / admin |
| created_at | BIGINT | Unix 时间戳（毫秒）|

### 初始数据
| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | admin123 | admin |

---

## 五、技术方案

- **密码哈希**：使用 `bcryptjs`（cost factor 10），强度哈希
- **Supabase RLS**：`adminUsers` 表开启 RLS，防止 anon 直接读取账号列表
- **会话存储**：`sessionStorage` 存储 `{ username, role }`
- **权限检查**：Zustand store 中的 `currentUser.role`，组件内判断
- **新增依赖**：`bcryptjs` + `@types/bcryptjs`
